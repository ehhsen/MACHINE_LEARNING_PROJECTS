## 🚀 How to Run

```bash
git clone https://github.com/ehhsen/MACHINE_LEARNING_PROJECTS.git
cd MACHINE_LEARNING_PROJECTS

# Install dependencies
pip install numpy pandas matplotlib scikit-learn jupyter

# Launch notebooks
jupyter notebook
```

Then open any `.ipynb` file from the browser UI.
